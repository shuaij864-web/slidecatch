# Code of Conduct

## Standard

Participants must communicate professionally, evaluate technical claims on evidence, and keep discussion focused on the project. Harassment, personal attacks, discriminatory conduct, doxxing, deliberate disruption, and publication of private course content or credentials are not acceptable.

## Security and privacy

Do not post authentication tokens, cookies, signed URLs, personally identifiable information, private class materials, or working exploit details in public issues. Use GitHub private vulnerability reporting for security matters.

## Enforcement

Maintainers may edit, hide, lock, or remove content and may restrict participation when conduct threatens contributors, users, third parties, or the security and legal boundaries of the project.

## Scope

This policy applies to repository issues, pull requests, discussions, code review, release channels, and other project-controlled spaces.
